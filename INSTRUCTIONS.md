# Simple Hangman - Instructions

## Getting Started

### Offline Usage
1. **Clone the Repository**:
    ```sh
    git clone https://github.com/IstinNew/SimpleHangman.git
    cd SimpleHangman
    ```

2. **Ensure Python is Installed**:
    - Make sure you have Python installed on your system. You can download it from [python.org](https://www.python.org/downloads/).

3. **Run the Game**:
    - Run the Python script to start the game:
    ```sh
    python hangman.py
    ```

### Online Usage (Google Colab)
1. **Open in Google Colab**:
    - Go to [Google Colab](https://colab.research.google.com/).
    - Click on `File` > `Upload Notebook`.
    - Upload the `hangman.ipynb` file from the repository.

2. **Run the Notebook**:
    - Follow the instructions in the notebook cells.
    - Run the code cells sequentially to start the Hangman game.

## How to Play
1. **Start the Game**:
    - The game will randomly select a word.
    - The word will be displayed as underscores, representing each letter.

2. **Make Guesses**:
    - Enter a letter to guess.
    - If the letter is in the word, it will be revealed.
    - If the letter is not in the word, an incorrect guess will be counted.

3. **Game Over**:
    - You have a limited number of incorrect guesses.
    - The game ends when you either guess the word correctly or run out of guesses.

## Additional Features
- The game includes a simple interface to make guesses and display the current state of the word.
- It can be easily extended to include more words or additional features such as difficulty levels.

## Troubleshooting
- **Offline**: Ensure you have the correct version of Python installed. If you encounter any issues, check the console for error messages and refer to the code comments for guidance.
- **Online**: Ensure you have a stable internet connection for Google Colab. If you encounter any issues, check the notebook cells for error messages and refer to the code comments for guidance.

Enjoy playing Simple Hangman!
